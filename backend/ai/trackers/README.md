# Трекеры

Модули трекинга лиц по видеопотоку:

- **ByteTrack** (планируется) — быстрый трекинг с Kalman фильтром
- **BoT-SORT** (планируется) — улучшенный трекинг с SDE

Трекеры используются для накопления эмбеддингов по track_id и выбора лучшего кадра.
