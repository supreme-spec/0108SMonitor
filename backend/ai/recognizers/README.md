# Рекогнайзеры

Модули распознавания лиц:

- **InsightFace** (активен) — основной движок с моделью buffalo_l
- **ArcFace** (планируется) — высокоточное распознавание
- **AdaFace** (планируется) — адаптивное распознавание для низкого качества

Каждый рекогнайзер реализует интерфейс `BaseModule` и может извлекать эмбеддинги из изображений.

## Интерфейс BaseModule

- `initialize()` — инициализация модуля
- `load_models()` — загрузка моделей
- `unload_models()` — выгрузка моделей
- `extract_embedding(image_bytes)` — извлечение эмбеддинга
