# Детекторы лиц

Модули детекции лиц в системе:

- **SCRFD** (активен) — быстрый и точный детектор от InsightFace
- **YOLO-Face** (планируется) — детектор на основе YOLOv8
- **RetinaFace** (планируется) — высокоточный детектор с атрибутами

Каждый детектор реализует интерфейс `BaseDetector` и может быть использован в зависимости от сценария, зоны или качества изображения.

## Интерфейс BaseDetector

- `detect(image_bytes)` — детектировать лица
- `detect_with_embedding(image_bytes)` — детектировать и извлечь эмбеддинги
